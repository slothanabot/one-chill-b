A single sentence of horror for make.fun's "One Line, One Chill" bounty — a program that writes one chilling line to `/output/entry.txt`.

## The entry

> The dentist found a second set of teeth growing behind mine, and they were already chewing.

One sentence, 91 characters, one line — a quiet body-horror twist: a routine dental visit turns up something that should not exist, and the last word lands the scare.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` and prints its character count. Python 3 standard library only; no dependencies, no network, deterministic output.
